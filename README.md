## 🔑 試験頻出ポイント（抜粋）

### 🟦 HTML編

- `ul` / `ol` / `dl` の内容は**空でもOK**
- `ol` 要素は `reversed` 属性で**逆順**にできる（論理属性）
- `dl` で用語の定義をする場合は **`dfn` 要素も必要**
- `tfoot` 要素は `tbody` / `tr` よりも**後に1つだけ**配置できる
- `table` 要素の `border` 属性は **HTML Living Standard で削除**済み
- `datalist` 要素は `input` 要素に関連付けて**サジェスト機能**を追加する
- `time` 要素は `data` 要素を**日時に特化**させた要素
- `DOCTYPE` 宣言は HTML5 では `<!DOCTYPE html>` のみ（大文字小文字不問）
- `meta charset` は **必ず `head` 要素の先頭付近**に記述する

### 🟪 CSS編

- CSSの書式には自由に空白を入れられるが、**セレクタだけは例外**
- `link` 要素・`style` 要素の **`type="text/css"` は省略可**（HTML5以降）
- `!important` 付きの優先順位は**逆転**する（UA > ユーザー > 製作者）
- 詳細度が最も高いのは **`style` 属性**（インラインスタイル）
- 詳細度は **A（ID）- B（属性系）- C（要素系）** の3桁で示す
- `hsl()` は **Hue（色相）/ Saturation（彩度）/ Lightness（明度）**
- `transparent` は CSS3 以降、**色の値が指定可能なすべての箇所**で使用可
- 不透明度は **0.0〜1.0 の単位なし数値**で指定する
- `currentColor` は**現在の `color` プロパティの値**を参照するキーワード

### 🟩 レスポンシブ編

- `viewport` の `width=device-width` は**デバイスの画面幅に合わせる**指定
- `srcset` 属性は画像の**解像度・幅に応じた切り替え**に使用する
- `picture` 要素は `source` 要素と組み合わせて**アート・ディレクション**を実現
- メディアクエリの `min-width` は**モバイルファースト**の基本指定

### 🟧 API・マルチメディア編

- `localStorage` はブラウザを閉じても**データが保持**される
- `sessionStorage` は**タブ・ウィンドウを閉じると消去**される
- `Geolocation API` の使用には**ユーザーの許可**が必要
- `Canvas API` は `getContext('2d')` で**2D描画コンテキスト**を取得する

### 🟦 Web規格・技術編

- HTML の仕様は **WHATWG** が策定する **HTML Living Standard** が主流
- **W3C** は CSS・SVG・アクセシビリティなど幅広い仕様を策定
- HTTP/2 は**ヘッダー圧縮・多重化**により HTTP/1.1 より高速
- HTTPS は **TLS（Transport Layer Security）** による暗号化通信
