② table / tr / th / td 要素

重要ポイント③：th は見出しセル（scope 属性で行・列を明示）。colspan / rowspan でセル結合 
<!-- 最小構成のテーブル -->
<table>
  <tr>
    <th scope="col">名前</th>
    <th scope="col">年齢</th>
    <th scope="col">職業</th>
  </tr>
  <tr>
    <th scope="row">山田太郎</th>
    <td>28</td>
    <td>エンジニア</td>
  </tr>
</table>

<!-- colspan：列方向に結合 / rowspan：行方向に結合 -->
<td colspan="2">2列分を結合</td>
<td rowspan="3">3行分を結合</td>

③ thead / tbody / tfoot 要素

重要ポイント④：tfoot は tbody・tr の後（最後）に1つだけ配置。HTML4 とは配置順序が異なる
・thead：テーブルのヘッダー行グループ（省略可・1つまで）
・tbody：テーブルのボディ行グループ（省略可・複数配置可・省略時は自動補完）
・tfoot：テーブルのフッター行グループ（省略可・1つまで・最後に配置） 
<table>
  <thead>
    <tr>
      <th>科目</th><th>前期</th><th>後期</th>
    </tr>
  </thead>

  <tbody>
    <tr><td>HTML</td><td>90</td><td>95</td></tr>
    <tr><td>CSS</td><td>85</td><td>88</td></tr>
  </tbody>

  <!-- tfoot は tbody の後に配置（HTML Living Standard） -->
  <tfoot>
    <tr><td>合計</td><td>175</td><td>183</td></tr>
  </tfoot>
</table>

④ caption / colgroup / col 要素

重要ポイント⑤：caption は table の最初の子要素。col は空要素。span 属性で複数列をまとめて指定

  <!-- colgroup / col：列のグループ化 -->
  <colgroup>
    <col style="background:#fef3c7;">  <!-- 1列目 -->
    <col span="2" style="background:#ebf8ff;">  <!-- 2〜3列目 -->
    <col style="background:#c6f6d5;">  <!-- 4列目 -->
  </colgroup>
  ...
</table>

⚠️ col 要素は空要素
・col 要素は空要素のため終了タグはありません

⑤ border 属性の廃止（HTML Living Standard）

重要ポイント⑥：HTML Living Standard では table 要素の border 属性は削除されている。枠線は CSS で指定する
⚠️ 試験重要ポイント③：border 属性の廃止

HTML4では <table border="1"> のように border 属性でテーブルの枠線を表示していました。

しかし HTML Living Standard（現在の標準仕様）では table 要素の border 属性は削除されています。

❌ <table border="1">　← 現在の仕様では不正

✅ テーブルの枠線は CSS で指定します 
<!-- ❌ 非推奨（HTML Living Standardでは削除） -->
<table border="1"> ... </table>

<!-- ✅ 推奨：CSSで枠線を指定 -->
<style>
  table { border-collapse: collapse; }
  th, td { border: 1px solid #ccc; padding: 8px; }
</style>
<table> ... </table>
✅ HTML 属性 vs CSS の使い分け原則
・構造・意味 → HTML 属性で指定
・見た目・スタイル → CSS で指定
・border / bgcolor / align / width（テーブル用） などの見た目に関する属性はすべてCSSに移行されています
