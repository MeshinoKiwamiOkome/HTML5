🗂️ CSS マルチカラム・フレキシブルボックス 学習サンプル

新聞のような段組みレイアウトを実現するマルチカラムと、 柔軟な一次元レイアウトを実現するフレキシブルボックス（Flexbox）を学びましょう。

【マルチカラムレイアウト】

① マルチカラムレイアウトとは

重要ポイント①：マルチカラムレイアウトとは、ボックスの内部を複数の段に分けるレイアウト
新聞・雑誌のような段組みをCSSだけで実現できます。 コンテナに column-count または column-width を指定するだけで、 子要素のコンテンツが自動的に複数の段に流し込まれます。

マルチカラムの仕組み

通常フロー（1段）
テキストは左から右、上から下へと流れます。段組みなしの通常のレイアウトです。テキストは左から右、上から下へと流れます。
→
マルチカラム（3段）
テキストは左から右、上から下へと流れます。段組みなしの通常のレイアウトです。テキストは左から右、上から下へと流れます。 
/* マルチカラムの基本 */
.container {
  column-count: 3;   /* 3段組みにする */
}

/* これだけで内部コンテンツが3段に流し込まれる */
✅ マルチカラムの特徴
・コンテナに指定するだけで、子要素のテキストが自動的に複数段に流れる
・レスポンシブ対応が容易（column-width で自動段数調整）
・新聞・雑誌・辞書のような段組みレイアウトに最適

② column-count プロパティ

重要ポイント②：columns プロパティで段数を指定するだけで段組みになる
column-count は段の数を整数で指定します。 ブラウザが自動的に各段の幅を均等に計算します。 
column-count: 1;     /* 1段（通常） */
column-count: 2;     /* 2段組み */
column-count: 3;     /* 3段組み */
column-count: auto;  /* column-widthに基づいて自動計算 */

column-count インタラクティブデモ

2

マルチカラムレイアウトは、ボックスの内部を複数の段に分けるレイアウト手法です。 新聞や雑誌のような段組みをCSSだけで実現できます。 column-countプロパティで段数を指定するだけで、テキストが自動的に複数の段に流し込まれます。 各段の幅はブラウザが均等に計算してくれます。 長いテキストも自然に次の段へと流れていきます。 これがマルチカラムレイアウトの基本的な動作です。

column-count: 2;

③ column-width プロパティ

/* 段の最小幅を指定する（段数は自動計算） */
column-width: 200px;  /* 各段が最低200pxになるよう段数を自動調整 */
column-width: auto;    /* column-countに基づいて自動計算 */

/* レスポンシブに段数が変わる例 */
.container {
  column-width: 250px;
  /* 幅800px → 3段、幅500px → 2段、幅250px → 1段（自動） */
}
⚠️ column-width の注意点
column-width は「最小幅の目安」であり、 実際の段幅はコンテナ幅・段数・ギャップを考慮してブラウザが計算します。 column-count と同時に指定した場合、 段数の上限として column-count が機能します。

column-width インタラクティブデモ

180px

column-widthは段の最小幅を指定します。 コンテナの幅に応じて段数が自動的に変わります。 ウィンドウサイズを変えると段数が変化するレスポンシブな段組みが実現できます。 幅が狭くなると段数が減り、広くなると段数が増えます。 これがcolumn-widthの便利なところです。

column-width: 180px;

④ columns プロパティ（ショートハンド）

重要ポイント②（再掲）：columns プロパティで段数を指定するだけで段組みになる
columns は column-width と column-count を まとめて指定できるショートハンドです。 
/* columns: column-width  column-count */
columns: 3;           /* column-count: 3（段数のみ指定） */
columns: 200px;       /* column-width: 200px（幅のみ指定） */
columns: 200px 3;    /* column-width: 200px / column-count: 3（両方指定） */
columns: auto;        /* 両方 auto */

/* 整数のみ → column-count として解釈 */
/* 長さのみ → column-width として解釈 */
指定値の例解釈
columns: 3column-count: 3（段数3）
columns: 200pxcolumn-width: 200px（最小幅200px）
columns: 200px 3column-width: 200px かつ column-count: 3（上限3段）
columns: autocolumn-width: auto / column-count: auto

⑤ column-gap プロパティ

/* 段と段の間隔（ガター）を指定 */
column-gap: normal;  /* ブラウザのデフォルト（通常1em程度） */
column-gap: 20px;    /* 固定値 */
column-gap: 2em;     /* フォントサイズ相対値 */
column-gap: 5%;      /* コンテナ幅に対する割合 */

/* gap プロパティ（Flexbox / Grid と共通） */
gap: 20px;  /* column-gap と同じ効果（マルチカラムでは行方向は無視） */

column-gap インタラクティブデモ

20px

column-gapは段と段の間隔を指定します。 ガターとも呼ばれます。 適切な間隔を設けることで読みやすさが向上します。 広すぎると間延びし、狭すぎると読みにくくなります。 バランスの良い間隔を設定しましょう。

column-count: 3; column-gap: 20px;

⑥ column-rule プロパティ

/* 段と段の間に罫線を引く（border と同じ書式） */
column-rule-width: 1px;
column-rule-style: solid;   /* none/solid/dashed/dotted/double など */
column-rule-color: #9f7aea;

/* ショートハンド：幅 スタイル 色 */
column-rule: 1px solid #9f7aea;
column-rule: 2px dashed #b794f4;
column-rule: 3px double #553c9a;

/* 罫線なし */
column-rule: none;

column-rule インタラクティブデモ

1px

column-ruleは段と段の間に罫線を引きます。 borderプロパティと同じ書式で指定できます。 幅・スタイル・色をショートハンドでまとめて指定できます。 罫線はcolumn-gapの中央に描画されます。 デザインのアクセントとして活用できます。

column-rule: 1px solid #9f7aea;
✅ column-rule の特徴
・罫線は段と段の間（column-gap の中央）に描画される
・罫線の幅は column-gap の幅に影響しない（border と異なりスペースを占有しない）
・border と同じ style 値（solid / dashed / dotted / double など）が使える

⑦ column-span プロパティ

/* 段をまたいで表示する（見出しなどに使用） */
column-span: none;  /* 通常（段をまたがない・デフォルト） */
column-span: all;   /* すべての段にまたがって表示 */

/* 使用例：段組みの中の見出しを全幅で表示 */
.container { column-count: 3; }
.container h2 { column-span: all; }  /* h2は全段にまたがる */

column-span: all のデモ

▲ column-span: all（全段にまたがる見出し）

この見出しの下からテキストが3段に分かれて流れます。 column-span: all を指定した要素は全段にまたがって表示されます。

新聞のように大見出しが全幅で表示され、その下に段組みのテキストが続くレイアウトが作れます。

column-span には none と all の2つの値しかなく、 特定の段数にまたがることはできません。

⚠️ column-span の注意点
・値は none と all の2つのみ（特定の段数指定は不可）
・column-span: all を指定した要素は、 前後のコンテンツの段組みを分断します
・column-span: all の要素自身には float を指定できません

【フレキシブルボックスレイアウト（Flexbox）】

⑧ フレキシブルボックスレイアウトとは

重要ポイント③：display: flex; を指定すると、その子要素は左から順に横に並ぶ
Flexbox は一次元（横または縦の一方向）のレイアウトシステムです。 コンテナに display: flex を指定するだけで、 直接の子要素（フレックスアイテム）が横に並びます。

Flexbox の基本構造

display: flex（デフォルト：左から横に並ぶ）
Item 1
Item 2
Item 3
/* フレックスコンテナの指定 */
.container {
  display: flex;  /* 子要素が左から横に並ぶ */
}

/* display: inline-flex：インラインのフレックスコンテナ */
.container {
  display: inline-flex;
}
用語説明
フレックスコンテナdisplay: flex を指定した要素
フレックスアイテムフレックスコンテナの直接の子要素
主軸（main axis）アイテムが並ぶ方向（デフォルトは横方向）
交差軸（cross axis）主軸に垂直な方向（デフォルトは縦方向）

⑨ flex-direction / flex-wrap

/* flex-direction：主軸の方向を指定 */
flex-direction: row;            /* 左→右（デフォルト） */
flex-direction: row-reverse;    /* 右→左 */
flex-direction: column;         /* 上→下 */
flex-direction: column-reverse; /* 下→上 */

/* flex-wrap：折り返しの設定 */
flex-wrap: nowrap;       /* 折り返さない（デフォルト） */
flex-wrap: wrap;         /* 折り返す（上→下） */
flex-wrap: wrap-reverse; /* 折り返す（下→上） */

/* flex-flow：flex-direction と flex-wrap のショートハンド */
flex-flow: row wrap;
flex-flow: column nowrap;

⑪ flex-grow / flex-shrink / flex-basis / flex

▼ マルチカラムレイアウト

column-width 長さ / auto 段の最小幅の目安。コンテナ幅に応じて段数が自動変化（レスポンシブ向き）
columns column-width column-count ショートハンド。整数のみ→column-count、長さのみ→column-width として解釈

▼ フレキシブルボックスレイアウト（コンテナ側）

flex-direction row / row-reverse / column / column-reverse 主軸の方向を指定。デフォルトは row（左→右）
flex-wrap nowrap / wrap / wrap-reverse 折り返しの設定。デフォルトは nowrap（折り返さない）
flex-flow direction wrap flex-direction と flex-wrap のショートハンド

align-items stretch / flex-start / center など 交差軸方向の揃え方（1行）。デフォルトは stretch
align-content flex-start / center / space-between など 複数行のときの交差軸方向の揃え方
gap 長さ / row-gap column-gap アイテム間の余白。row-gap / column-gap を個別指定も可

order 整数（デフォルト: 0） 表示順序。小さい値が先に表示される
