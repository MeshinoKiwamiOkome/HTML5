① セレクタの種類と組み合わせのルール

/* ===== セレクタの種類一覧 ===== */
p           { } /* タイプセレクタ：要素名で指定 */
*           { } /* ユニバーサルセレクタ：すべての要素 */
.class      { } /* クラスセレクタ */
#id         { } /* IDセレクタ */
[attr]      { } /* 属性セレクタ */

::before    { } /* 擬似要素 */

/* ===== 組み合わせのルール ===== */
/* グループ化（カンマ区切り）：複数セレクタに同じスタイル */
h1, h2, h3 { color: #553c9a; }

/* 複合セレクタ（スペースなし連結）：条件を重ねる */
p.highlight        { } /* p要素 かつ .highlight クラス */
input[type="text"] { } /* input要素 かつ type="text" */
a:hover            { } /* a要素 かつ :hover 状態 */

② 属性セレクタ

重要ポイント①：属性セレクタの記号はしっかりと覚える
記号の違いで「完全一致」「前方一致」「後方一致」「部分一致」などが変わります。

属性セレクタ記号セレクター インタラクティブデモ

カードをクリックして各記号の意味と使用例を確認しましょう。

[attr]
属性が存在する要素
[attr="val"]
属性値が完全一致
[attr~="val"]
スペース区切りの値の1つに一致
[attr|="val"]
完全一致 または「val-」で始まる
[attr^="val"]
値が「val」で始まる（前方一致）
[attr$="val"]
値が「val」で終わる（後方一致）
[attr*="val"]
値に「val」が含まれる（部分一致）
[attr="val" i]
大文字・小文字を区別しない

▼ 属性セレクタのライブデモ

httpsリンク（緑色・太字）　 httpリンク（通常）　 PDFリンク（📄アイコン付き）

⚠️ 記号の覚え方
・^（キャレット）= 前方一致　← 正規表現の「文字列の先頭」と同じ
・$（ドル）= 後方一致　← 正規表現の「文字列の末尾」と同じ
・*（アスタリスク）= 部分一致　← ワイルドカードと同じ
・~（チルダ）= スペース区切りの値の1つ
・|（パイプ）= 完全一致またはハイフン区切りの先頭

③ 擬似クラス

重要ポイント②：擬似クラスの式「an+b」の指定方法をしっかりと覚える
:nth-child(an+b) の a・n・b の意味を理解しましょう。 
/* リンクの状態（LVHA の順で記述するのが推奨） */
a:link    { color: blue; }
a:visited { color: purple; }
a:hover   { color: red; }
a:active  { color: orange; }

/* 構造的擬似クラス */
li:first-child   { } /* 最初の子要素 */
li:last-child    { } /* 最後の子要素 */
p:first-of-type { } /* 同種の最初の要素 */
:root           { } /* ルート要素（html要素） */
p:empty         { } /* 子要素・テキストがない要素 */

/* :nth-child(an+b) の式 */
/* a=間隔, n=0,1,2,3..., b=オフセット */
li:nth-child(2n)   { } /* 偶数番目（even と同じ） */
li:nth-child(2n+1) { } /* 奇数番目（odd と同じ） */
li:nth-child(3n+1) { } /* 1,4,7,10... */
li:nth-child(n+3)  { } /* 3番目以降すべて */
li:nth-child(-n+3) { } /* 最初の3つ（1,2,3） */

▼ nth-child のライブデモ

  • 1番目（:first-child → 紫・太字）
  • 2番目（:nth-child(2n) → 背景薄紫）
  • 3番目（:nth-child(3n+1) → 左ボーダー）
  • 4番目（:nth-child(2n) → 背景薄紫）
  • 5番目（:last-child → 赤・太字）

④ 擬似要素

重要ポイント③：擬似要素の先頭のコロンは、CSS3からコロン2つになった
・CSS2では :before（コロン1つ）でしたが、CSS3以降では ::before（コロン2つ）が正式です
・擬似クラス（:hover）との区別のためにコロンが2つになりました
・後方互換性のため :before（1つ）も多くのブラウザで動作しますが、現在は ::before（2つ）が推奨

擬似要素セレクター インタラクティブデモ

擬似要素を選択して、使い方と注意点を確認しましょう。

▼ 擬似要素のライブデモ

これは ::first-line（最初の行が紫・太字）と ::first-letter（最初の文字が大きく紫）のデモです。テキストが複数行になると効果がよくわかります。

before・afterで括弧を追加

擬似要素説明CSS2記法（非推奨）
::before要素の直前にコンテンツ挿入:before
::after要素の直後にコンテンツ挿入:after
::first-line最初の行:first-line
::first-letter最初の文字:first-letter
::selection選択されたテキストなし（CSS3追加）
::placeholderプレースホルダーなし（CSS3追加）
::markerリストマーカーなし（CSS4追加）

Q7. コード穴埋め問題

__A__ 〜 __F__ に適切なセレクタ・記号・値を入力してください。

/* A：PDFリンクの後方一致 */
a[href__A__".pdf"] { color: red; }

/* B：httpsリンクの前方一致 */
a[href__B__"https"] { color: green; }

/* C：テーブルの偶数行（even と同じ） */
tr:nth-child(__C__) { background: #f0f0f0; }

/* D：h2の直後のpのみ（隣接兄弟） */
h2 __D__ p { margin-top: 0; }

/* E：ulの直接の子liのみ（子結合子） */
ul __E__ li { list-style: disc; }

/* F：::beforeの必須プロパティ */
.icon::before {
    __F__: "★";
}
