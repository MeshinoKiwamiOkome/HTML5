🏷️ HTML5 グローバル属性 学習サンプル

すべてのHTML要素に共通して使えるグローバル属性の役割と使い方を学びましょう。

① 属性と要素のおさらい

重要ポイント①：属性は開始タグ内に記述する追加情報。要素はタグ全体のこと
グローバル属性を学ぶ前に、「要素」と「属性」の違いをしっかり確認しましょう。

🧱 要素（Element）

・開始タグ〜終了タグ全体のこと
・コンテンツに意味・構造を与える
・例：<p>、<h1>、<a>

<p>本文テキスト</p>
↑ これ全体が「p要素」

🔧 属性（Attribute）

・開始タグ内に記述する追加情報
・要素に性質・設定を付け加える
・例：class、id、href

<a href="url">リンク</a>
↑ href="url" が「属性」 
<!-- 要素・属性・属性値の関係 -->
<a href="https://example.com"
   class="btn-primary"
   id="top-link"
   target="_blank">
  リンクテキスト
</a>
<!-- href / class / id / target はすべて「属性」 -->
<!-- "https://..." / "btn-primary" などは「属性値」 -->
⚠️ 属性の書き方ルール
・属性は開始タグ内にのみ記述できます（終了タグには書けません）
・属性値はダブルクォート（"）で囲むのが推奨です
・同じ属性を同じ要素に2回以上指定することはできません
・値を持たない論理属性（disabled、checked など）は 値を省略して属性名だけ書けます

③ class 属性

重要ポイント③：class 属性の値には「種類や分類を示す名前」を指定する。複数要素に同じ値OK
・class 属性はCSSのスタイル適用やJavaScriptの操作対象を指定するために使います
・複数の要素に同じclass名を指定できます（id属性との大きな違い）
・1つの要素に複数のclass名をスペース区切りで指定できます 
<!-- 複数要素に同じclass名を指定できる -->
<p class="highlight">強調テキスト1</p>
<p class="highlight">強調テキスト2</p>

<!-- スペース区切りで複数のclass名を指定 -->
<button class="btn btn-primary btn-large">
  送信する
</button>

<!-- CSSでの参照（.クラス名） -->
/* .highlight { background: yellow; } */
/* .btn-primary { background: #4299e1; color: #fff; } */

<!-- JavaScriptでの参照 -->
/* document.querySelectorAll('.highlight') */
/* el.classList.add('active') */
/* el.classList.remove('hidden') */

class 属性ビルダー インタラクティブデモ

class 名を入力してスペース区切りで複数指定できることを確認しましょう。

⚠️ class 属性の命名ルール
・見た目ではなく役割・種類・分類を示す名前にする
❌ class="red-text"　← 見た目（色）を表す名前（避けるべき）
✅ class="error-message"　← 役割を表す名前（推奨）

・数字で始めることはできません（class="1st" は不正）
・スペースは区切り文字として使われるため、class名にスペースは含められません

④ id 属性

重要ポイント④：id 属性の値には「ほかの要素と重複しない固有の名前」を指定する
・id 属性は文書内で一意（ユニーク）な識別子を指定します
・同じid値を複数の要素に指定することはできません
・ページ内リンク（アンカーリンク）のターゲットとして使えます 
<!-- 基本的な使い方 -->
<h2 id="section-intro">はじめに</h2>

<!-- ページ内リンクのターゲット -->
<a href="#section-intro">「はじめに」へ移動</a>

<!-- CSSでの参照（#id名） -->
/* #section-intro { color: #2b6cb0; } */

<!-- JavaScriptでの参照 -->
/* document.getElementById('section-intro') */

<!-- ❌ 同じid値を複数の要素に指定してはいけない -->
<p id="intro">段落1</p>
<p id="intro">段落2</p>  <!-- 不正：id重複 -->
比較項目class 属性id 属性
文書内での重複 ✅ 複数要素に同じ値を指定可 ❌ 文書内で一意（重複不可）
1要素への複数指定 ✅ スペース区切りで複数指定可 ❌ 1つの値のみ
CSSセレクタ .クラス名 #id名
ページ内リンク ❌ 使用不可 ✅ href="#id名" で参照可
主な用途 スタイル・グループ操作 一意識別・アンカー・JS操作

⑤ lang / title / dir 属性

重要ポイント⑤：lang は言語指定、title はツールチップ、dir はテキスト方向 
<!-- lang：言語コードの指定 -->
<html lang="ja">
<p>日本語の中に<span lang="en">English</span>が含まれる</p>

<!-- title：ツールチップ -->
<abbr title="HyperText Markup Language">HTML</abbr>

<!-- dir：テキスト方向 -->
<p dir="ltr">Left to Right</p>
<p dir="rtl">مرحبا بالعالم</p>
<p dir="auto">自動判定</p>

⑥ tabindex 属性

重要ポイント⑥：tabindex でタブキーのフォーカス順序を制御する。-1 はJSでのみフォーカス可
・tabindex 属性はキーボードの Tab キーによるフォーカス順序を制御します
・通常フォーカスできない要素（div、span など）にもフォーカス可能にできます 
<!-- tabindex="0"：通常のタブ順序に追加 -->
<div tabindex="0">Tabキーでフォーカス可能なdiv</div>

<!-- tabindex="-1"：Tabキーでは到達しないがJSでフォーカス可能 -->
<div tabindex="-1" id="modal">モーダルダイアログ</div>

<!-- tabindex="1以上"：明示的な順序指定（非推奨） -->
<input tabindex="3" type="text">  <!-- 3番目 -->
<input tabindex="1" type="text">  <!-- 1番目 -->
<input tabindex="2" type="text">  <!-- 2番目 -->

⑦ カスタムデータ（data-*）属性

重要ポイント⑦：HTML5以降では data-〇〇〇 の書式で独自の属性を追加できる
・data-* 属性はHTML要素に独自のデータを埋め込むための仕組みです
・data- の後に任意の名前を付けて使います
・JavaScriptから dataset プロパティで簡単にアクセスできます 
<!-- data-*属性の基本 -->
<button data-user-id="12345"
        data-action="delete"
        data-confirm-msg="本当に削除しますか？">
  削除する
</button>

<!-- JavaScriptからのアクセス -->
const btn = document.querySelector('button');
btn.dataset.userId     // → "12345"（data-user-id）
btn.dataset.action     // → "delete"
btn.dataset.confirmMsg // → "本当に削除しますか？"（data-confirm-msg）
// ※ ハイフンはキャメルケースに変換される
// data-user-id → dataset.userId
// data-confirm-msg → dataset.confirmMsg

⚠️ data-* 属性の命名ルール
・必ず data- で始める
・data- の後に少なくとも1文字以上の名前が必要

📌 グローバル属性 まとめ一覧

属性役割重要ポイント
class 種類・分類を示す名前 複数要素に同じ値OK。スペース区切りで複数値指定可。CSSは .クラス名
id 固有の識別名 文書内で一意（重複不可）。ページ内リンクのターゲットに使用可。CSSは #id名
lang 言語コードの指定 BCP 47言語タグ（ja / en / zh-CN など）。スクリーンリーダー・SEOに影響
title 補足情報・ツールチップ マウスオーバーでツールチップ表示。スマホでは表示されない
dir テキストの書字方向 ltr（左→右）/ rtl（右→左）/ auto（自動判定）
tabindex タブキーのフォーカス順序 0：通常順序に追加 / -1：TabキーNG・JSでフォーカス可 / 正の値：非推奨
data-* カスタムデータ属性 HTML5以降。data-で始まる任意名。大文字不可。datasetでJSアクセス可。ハイフン→キャメルケース変換
