直線状・放射状グラデーション、リスト関連プロパティ、テーブル関連プロパティ、 content プロパティによるコンテンツ追加を学びましょう。

① 直線状のグラデーション（linear-gradient）

重要ポイント①：グラデーション指定の基本形は、方向または中心位置と色を2色指定すればOK
linear-gradient(方向, 色1, 色2) の形が基本です。 方向を省略すると上から下へのグラデーションになります。 background-image プロパティの値として指定します。 
/* 基本形：方向と2色を指定 */
background-image: linear-gradient(to right, #9f7aea, #4299e1);

/* 方向の指定方法 */
background-image: linear-gradient(to bottom, #9f7aea, #4299e1);  /* 上→下（デフォルト） */
background-image: linear-gradient(to right, #9f7aea, #4299e1);   /* 左→右 */
background-image: linear-gradient(to top right, #9f7aea, #4299e1); /* 左下→右上 */
background-image: linear-gradient(45deg, #9f7aea, #4299e1);       /* 45度 */
background-image: linear-gradient(135deg, #9f7aea, #4299e1);      /* 135度 */

/* 3色以上のグラデーション */
background-image: linear-gradient(to right, #9f7aea, #4299e1, #68d391);

/* 色停止点（カラーストップ）を指定 */
background-image: linear-gradient(to right,
  #9f7aea 0%,
  #4299e1 50%,
  #68d391 100%);

/* 透明を使ったグラデーション */
background-image: linear-gradient(to right, transparent, #9f7aea);

/* 繰り返しグラデーション */
background-image: repeating-linear-gradient(45deg,
  #9f7aea 0px, #9f7aea 10px,
  #e9d8fd 10px, #e9d8fd 20px);

⚠️ linear-gradient の注意点
・linear-gradient() は background-image の値として指定します （background-color には使えません）
・角度の 0deg は下から上（時計回りで増加）です
・to right = 90deg、to bottom = 180deg

② 放射状のグラデーション（radial-gradient）

重要ポイント①（再掲）：中心位置と色を2色指定すればOK
radial-gradient(形状 at 中心位置, 色1, 色2) の形が基本です。 形状・中心位置を省略すると楕円形・中央からのグラデーションになります。 
/* 基本形：中心から外側へ */
background-image: radial-gradient(#9f7aea, #4299e1);

/* 形状の指定 */
background-image: radial-gradient(circle, #9f7aea, #4299e1);   /* 円形 */
background-image: radial-gradient(ellipse, #9f7aea, #4299e1);  /* 楕円形（デフォルト） */

/* 中心位置の指定（at キーワード） */
background-image: radial-gradient(circle at center, #9f7aea, #4299e1);
background-image: radial-gradient(circle at top left, #9f7aea, #4299e1);
background-image: radial-gradient(circle at 30% 70%, #9f7aea, #4299e1);

/* サイズキーワード */
background-image: radial-gradient(circle closest-side at center, #9f7aea, #4299e1);
background-image: radial-gradient(circle farthest-corner at center, #9f7aea, #4299e1);

/* 3色・色停止点あり */
background-image: radial-gradient(circle at center,
  #fff 0%,
  #9f7aea 50%,
  #553c9a 100%);

/* 繰り返し放射状グラデーション */
background-image: repeating-radial-gradient(circle,
  #9f7aea 0px, #9f7aea 10px,
  #e9d8fd 10px, #e9d8fd 20px);

④ テーブル関連のプロパティ

重要ポイント②：セルのボーダーを1本にするには border-collapse: collapse; を指定する
デフォルト（separate）では隣接するセルのボーダーが2本になります。 collapse を指定すると隣接するボーダーが1本に折りたたまれます。 
/* border-collapse：ボーダーの折りたたみ */
border-collapse: separate;  /* 隣接ボーダーを分離（デフォルト） */
border-collapse: collapse;  /* 隣接ボーダーを1本に折りたたむ */

/* border-spacing：セル間の間隔（separate のときのみ有効） */
border-spacing: 4px;        /* 縦横ともに4px */
border-spacing: 8px 4px;    /* 横8px・縦4px */

/* caption-side：キャプションの位置 */
caption-side: top;     /* テーブルの上（デフォルト） */
caption-side: bottom;  /* テーブルの下 */

/* empty-cells：空セルのボーダー・背景の表示 */
empty-cells: show;  /* 表示する（デフォルト） */
empty-cells: hide;  /* 非表示（separate のときのみ有効） */

/* table-layout：テーブルの幅の計算方法 */
table-layout: auto;   /* コンテンツに応じて自動計算（デフォルト） */
table-layout: fixed;  /* 最初の行の幅で固定（高速レンダリング） */

⑤ 内容を追加するプロパティ（content）

重要ポイント③：q要素で指定される引用符の種類は quotes プロパティで設定する
content プロパティは ::before / ::after 擬似要素と 組み合わせて使い、要素の前後にコンテンツを挿入します。 また quotes プロパティで <q> 要素の引用符を変更できます。 
/* content プロパティの値 */

/* 文字列を挿入 */
.required::after {
  content: " *";
  color: red;
}

/* 属性値を挿入 */
a::after {
  content: " (" attr(href) ")";  /* リンクURLを表示 */
}

/* 画像を挿入 */
.icon::before {
  content: url('icon.png');
}

/* カウンターを挿入 */
ol { counter-reset: my-counter; }
li { counter-increment: my-counter; }
li::before {
  content: counter(my-counter) ". ";
}

/* 引用符を挿入（open-quote / close-quote） */
q::before { content: open-quote; }
q::after  { content: close-quote; }

/* 空文字（clearfixなどに使用） */
.clearfix::after {
  content: "";
  display: block;
  clear: both;
}

/* none：擬似要素を非表示 */
::before { content: none; }

⑥ quotes プロパティ

重要ポイント③（再掲）：q要素で指定される引用符の種類は quotes プロパティで設定する
quotes プロパティで <q> 要素の 開始引用符・終了引用符のペアを指定します。 ネストされた <q> 要素には2番目以降のペアが使われます。 
/* quotes: "開始引用符" "終了引用符" ["ネスト開始" "ネスト終了" ...] */

/* 日本語の引用符（「」） */
:lang(ja) {
  quotes: "「" "」" "『" "』";
}

/* 英語の引用符（" "） */
:lang(en) {
  quotes: '"' '"' "'" "'";
}

/* フランス語のギュメ（« »） */
:lang(fr) {
  quotes: "«" "»" "‹" "›";
}

/* カスタム引用符 */
.custom-quote {
  quotes: "【" "】";
}

/* content と組み合わせて使用 */
q::before { content: open-quote; }
q::after  { content: close-quote; }

quotes のデモ

日本語（「」『』）
これは引用文です。ネストされた引用も使えます。
英語（" " ' '）
This is a quote. Nested quote here.
フランス語（« »）
C'est une citation. Citation imbriquée.
カスタム（【】〔〕）
カスタム引用符です。ネスト引用も変わります。
⚠️ quotes プロパティの注意点
・quotes プロパティを指定しただけでは引用符は表示されません
・q::before { content: open-quote; } と q::after { content: close-quote; } の指定が必要です
・ブラウザのデフォルトスタイルシートに q 要素の引用符スタイルが含まれているため、 通常は自動的に表示されます

counter-reset / counter-increment（カウンター関連）

/* カウンターの定義と使用 */
.chapter-list {
  counter-reset: chapter;     /* カウンターを0にリセット */
  list-style: none;
}
.chapter-list li {
  counter-increment: chapter; /* カウンターを1増やす */
}
.chapter-list li::before {
  content: "第" counter(chapter) "章 ";
  font-weight: bold;
  color: #9f7aea;
}

/* counter-reset の初期値を指定 */
counter-reset: chapter 0;   /* 0から開始（デフォルト） */
counter-reset: chapter 4;   /* 4から開始（次の li で5になる） */

/* counter-increment の増分を指定 */
counter-increment: chapter 2; /* 2ずつ増やす */
