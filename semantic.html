① figure / figcaption

重要ポイント①：figure は本文から参照される独立したコンテンツを包む。figcaption はそのキャプション
・<figure> ― 画像・図・コードなど、本文から参照される独立したコンテンツを包む
・<figcaption> ― figure のキャプション。figure の最初か最後の子要素として記述
・figure を削除しても本文の意味が成立するような補足的コンテンツに使う

基本の使い方

<figure>
  <img src="sample.jpg" alt="サンプル画像">
  <figcaption>図1：サンプル画像の説明</figcaption>
</figure>

<!-- figcaption は最初か最後の子要素として記述 -->
<figure>
  <figcaption>図2：先頭に置くことも可能</figcaption>
  <img src="chart.png" alt="グラフ">
</figure>

② details / summary

重要ポイント②：details はクリックで開閉する折りたたみコンテンツ。open 属性で初期展開
・<details> ― クリックで開閉できる折りたたみコンテンツを作る
・<summary> ― details の見出し部分（クリック対象）。省略すると「詳細」と表示される
・open 属性を付けると初期状態で展開される
▶ HTML5 とは何ですか？（クリックして開く）

HTML5 は HyperText Markup Language のバージョン5です。
セマンティックな要素・マルチメディア対応・APIの充実が特徴です。

▶ open属性あり（最初から開いている）

open 属性を付けると、ページ読み込み時から展開された状態になります。

<details>
  <summary>クリックして開く</summary>
  <p>ここに詳細コンテンツ</p>
</details>

<!-- open属性で最初から展開 -->
<details open>
  <summary>最初から開いている</summary>
  <p>コンテンツ</p>
</details>

③ menu

重要ポイント③：menu はコマンド・ボタンのリストを表すセマンティックな要素
・<menu> ― コマンドやボタンのリストを表すセマンティックな要素
・<ul> と同じブロックレベルのリストだが、インタラクティブなコマンド群に使う意味的な違いがある
・ツールバーやアクションボタン群のマークアップに適している

ドキュメント操作メニュー：

    •
    ボタンをクリックしてください
    <!-- menu：インタラクティブなコマンド群 -->
<menu>
  <li><button>新規作成</button></li>
  <li><button>保存</button></li>
  <li><button>印刷</button></li>
</menu>

<!-- ul との違い：意味的にコマンド群であることを示す -->
<ul>  <!-- 一般的なリスト -->
<menu> <!-- インタラクティブなコマンドのリスト -->

    ④ iframe

    重要ポイント④：iframe は別のHTMLページを埋め込む。sandbox 属性でセキュリティ制限をかけられる
    ・<iframe> ― 別のHTMLページや外部コンテンツをページ内に埋め込む（インラインフレーム）
    ・title 属性はアクセシビリティのために必須
    ・sandbox 属性でセキュリティ制限をかけられる
    ・loading="lazy" で遅延読み込みが可能

    ※ セキュリティポリシーにより表示されない場合があります

    <iframe
  src="https://example.com"
  title="example.com の埋め込み"  <!-- アクセシビリティのために必須 -->
  width="100%"
  height="200"
  loading="lazy"                   <!-- 遅延読み込み -->
  sandbox="allow-scripts allow-same-origin">
</iframe>

    ⑥ script / noscript

    重要ポイント⑥：defer はHTML解析後に順序保証で実行。async はダウンロード完了次第実行（順序保証なし）
    ・<script> ― JavaScriptを埋め込む・外部JSファイルを読み込む
    ・defer 属性：HTML解析完了後にJS実行（DOMの準備後）。順序保証あり
    ・async 属性：HTML解析と並行してJS取得・完了次第実行。順序保証なし
    ・<noscript> ― JSが無効な環境向けの代替コンテンツを提供する

    ⏳ JavaScriptで書き換えられます...

    defer / async / なし の比較

    defer
    ・HTML解析と並行してダウンロード
    ・HTML解析完了後に実行
    ・順序保証あり（記述順に実行）
    ・DOMを操作するスクリプトに最適
    async
    ・HTML解析と並行してダウンロード
    ・ダウンロード完了次第すぐ実行
    ・順序保証なし
    ・他スクリプトに依存しない独立したスクリプトに適する
    なし（デフォルト）
    ・HTML解析をブロックして実行
    ・ダウンロード・実行が完了するまで解析停止
    ・</body> 直前に置くことで影響を最小化できる

    defer / async シミュレーターデモ

    属性を選択して、スクリプトの読み込みタイミングの違いを確認しましょう。 

    <!-- インラインスクリプト -->
<script>
  console.log('Hello HTML5');
</script>

<!-- 外部ファイル読み込み -->
<script src="app.js" defer></script>  <!-- HTML解析後・順序保証あり -->
<script src="lib.js" async></script>  <!-- 完了次第実行・順序保証なし -->

<!-- JS無効時の代替 -->
<noscript>
  <p>JavaScriptを有効にしてください。</p>
</noscript>

    ⑦ dialog

    重要ポイント⑦：dialog はネイティブのモーダルダイアログ。showModal() でモーダル表示、close() で閉じる
    ・<dialog> ― モーダルダイアログ・ポップアップを表すネイティブHTML要素
    ・open 属性があると表示される
    ・JS の .show() で通常表示、.showModal() でモーダル表示
    ・.close(returnValue) で閉じる。戻り値を渡すことができる
    ・::backdrop 疑似要素で背景をスタイリングできる

    📢 モーダルダイアログ

    これは showModal() で開いたモーダルです。
    背景（::backdrop）が表示され、背景クリックでは閉じません。

    💬 通常ダイアログ

    これは show() で開いた通常表示です。
    モーダルではないため背景も操作できます。
    ダイアログを開いてください
    <button onclick="document.getElementById('myDialog').showModal()">
  ダイアログを開く
</button>

<dialog id="myDialog">
  <h3>お知らせ</h3>
  <p>ダイアログの内容</p>
  <button onclick="document.getElementById('myDialog').close('OK')">
    閉じる
  </button>
</dialog>

/* ::backdrop で背景をスタイリング */
dialog::backdrop {
  background: rgba(0,0,0,0.45);
}

    ⑧ template / slot

    重要ポイント⑧：template はページ読み込み時にレンダリングされないHTML雛形。JS で複製して使う
    ・<template> ― ページ読み込み時にはレンダリングされないHTMLの雛形。JSで複製して使う
    ・content プロパティで中身の DocumentFragment を取得できる
    ・<slot> ― Web Components（Shadow DOM）で使うコンテンツ挿入口
    ・name 属性で名前付きスロットを定義できる

    template インタラクティブデモ（動的カード生成）

    ボタンを押すと template を複製してカードを動的に追加します。

    ボタンを押してカードを追加してください
    <!-- template定義（画面には表示されない） -->
<template id="myTemplate">
  <div class="card">
    <h3 class="title"></h3>
    <p  class="body"></p>
  </div>
</template>

/* JavaScriptで複製してDOMに追加 */
const tmpl  = document.getElementById('myTemplate');
const clone = tmpl.content.cloneNode(true);  /* true = 深いコピー */
clone.querySelector('.title').textContent = 'タイトル';
document.body.appendChild(clone);

    ⑨ canvas

    重要ポイント⑨：canvas は JS で2D/3Dグラフィックを描画する領域。width/height 属性と CSS サイズは別物
    ・<canvas> ― JSで2D/3Dグラフィックを描画するための領域
    ・width / height 属性で描画解像度を指定（CSSサイズとは別）
    ・getContext('2d') で2D描画コンテキストを取得
    ・canvas自体はピクセルベース（SVGはベクターベース）
    ・JS非対応環境向けにタグ内に代替テキストを書ける
    ※ お使いのブラウザはcanvasに対応していません

    ⬆️ JavaScriptで四角・円・三角・テキストを描画しています

    canvas ライブ描画デモ

    スライダーで描画パラメータを変えてリアルタイムに確認しましょう。

    #4299e1
    60 
    <canvas id="myCanvas" width="500" height="160">
  ※ canvasに対応していません（代替テキスト）
</canvas>

const ctx = document.getElementById('myCanvas').getContext('2d');

/* 四角形 */
ctx.fillStyle = '#4299e1';
ctx.fillRect(20, 40, 80, 80);

/* 円 */
ctx.beginPath();
ctx.arc(200, 80, 45, 0, Math.PI * 2);
ctx.fillStyle = '#f6ad55';
ctx.fill();

/* テキスト */
ctx.font = 'bold 14px sans-serif';
ctx.fillText('Hello Canvas!', 300, 80);
    ⚠️ canvas の注意点
    ・width・height 属性はCSSのサイズ指定とは別物です。 CSSでサイズを変えると描画が引き伸ばされます
    ・描画結果はビットマップのため、拡大すると粗くなります（SVGと異なる点）
