🖼️ HTML5 画像・動画・音声

img / picture / source / video / audio / track / embed / map / area / object の役割と使い方を学びましょう。

① img 要素

重要ポイント①：img は画像を埋め込む空要素。alt は特別なケースを除き必須。width/height はピクセル整数値のみ
・<img> は画像を埋め込む空要素です
・src 属性（画像URL）と alt 属性（代替テキスト）が基本セットです
・width / height 属性でサイズを指定できますが、 パーセント値は指定できません（ピクセル整数値のみ）
⚠️ 試験重要ポイント①：alt 属性の省略

通常、alt 属性は必須ですが、以下の特別なケースでは省略できます。

✅ 省略できるケース：
　・画像がキャプション（<figcaption> など）によって説明されている場合
　・純粋に装飾目的の画像（この場合は alt="" と空文字を指定するのが推奨）

❌ 省略してはいけないケース：
　・画像がコンテンツとして意味を持つ場合
　・画像がリンクになっている場合

⚠️ alt 属性を省略するのと alt=""（空文字）は意味が異なります。
　・省略：スクリーンリーダーがファイル名を読み上げる場合がある
　・空文字：スクリーンリーダーがその画像をスキップする
⚠️ 試験重要ポイント②：width / height 属性の値

width / height 属性に指定できる値は ピクセル値（整数）のみです。

✅ <img width="300" height="200">　← 正しい（単位なし整数）
❌ <img width="300px" height="200px">　← 不正（px単位は書かない）
❌ <img width="50%" height="50%">　← 不正（パーセント値は指定不可） 
<!-- 基本的な書き方 -->
<img src="photo.jpg"
     alt="富士山の写真"
     width="800"
     height="600">

<!-- 装飾目的の画像（altは空文字） -->
<img src="decoration.png" alt="">

<!-- figcaptionで説明されている場合はaltを省略可 -->
<figure>
  <img src="chart.png">
  <figcaption>2025年度 売上グラフ</figcaption>
</figure>

<!-- loading属性：遅延読み込み -->
<img src="photo.jpg" alt="写真" loading="lazy">

② picture 要素 / source 要素（画像）

重要ポイント②：picture 内の source 要素は srcset が必須。video/audio 内の source は src が必須
・<picture> は複数の画像候補を定義し、ブラウザが最適なものを選んで表示する要素です
・必ず最後に <img> 要素（フォールバック）を含める必要があります
⚠️ 試験重要ポイント：picture 内の source 要素の必須属性

<picture> 内の <source> 要素には srcset 属性が必須です。

✅ srcset + media 属性の組み合わせ
✅ srcset + type 属性の組み合わせ
✅ srcset のみでも動作する（media / type は任意）

※ video / audio 内の source 要素は src 属性が必須（srcset は使わない）

③ video 要素

重要ポイント③：video は動画を埋め込む要素。controls / poster / autoplay / muted などの属性を持つ
・<video> は動画を埋め込む要素です
・src 属性で直接指定するか、子要素の <source> で複数フォーマットを指定します
・ブラウザが対応していない場合のフォールバックテキストを内部に書けます 
<!-- 基本的な書き方 -->
<video src="movie.mp4"
       controls
       width="640"
       height="360">
  お使いのブラウザは動画再生に対応していません。
</video>

<!-- 複数フォーマット + poster（source要素） -->
<video controls width="640" height="360"
       poster="thumbnail.jpg">
  <!-- video内のsource要素はsrc属性が必須 -->
  <source src="movie.mp4"  type="video/mp4">
  <source src="movie.webm" type="video/webm">
  お使いのブラウザは動画再生に対応していません。
</video>

④ audio 要素

重要ポイント④：audio は音声を埋め込む要素。video とほぼ同じ構造だが width/height 属性はない
・<audio> は音声を埋め込む要素です
・基本的な構造は video 要素と同じです
・width / height 属性はありません（音声のみのため） 
<!-- 基本的な書き方 -->
<audio src="sound.mp3" controls>
  お使いのブラウザは音声再生に対応していません。
</audio>

<!-- 複数フォーマットの指定（source要素） -->
<audio controls>
  <!-- audio内のsource要素もsrc属性が必須 -->
  <source src="sound.mp3"  type="audio/mpeg">
  <source src="sound.ogg"  type="audio/ogg">
  <source src="sound.wav"  type="audio/wav">
  お使いのブラウザは音声再生に対応していません。
</audio>

⑤ track 要素

重要ポイント⑤：track は video/audio に字幕・キャプション・チャプターを追加する空要素
・<track> は video / audio 要素に テキストトラックを追加する空要素です
・WebVTT 形式（.vtt）のファイルを指定します
・kind 属性でトラックの種類を指定します 
<video controls src="movie.mp4">
  <!-- 日本語字幕（デフォルト表示） -->
  <track kind="subtitles"
         src="subtitles-ja.vtt"
         srclang="ja"
         label="日本語"
         default>
  <!-- 英語字幕 -->
  <track kind="subtitles"
         src="subtitles-en.vtt"
         srclang="en"
         label="English">
  <!-- チャプター情報 -->
  <track kind="chapters"
         src="chapters.vtt"
         srclang="ja">
</video>

track kind 属性 インタラクティブデモ

kind 属性の値を選択して、各トラックの用途を確認しましょう。

kind 属性の値説明

⑥ embed 要素 / object 要素

重要ポイント⑥：embed は空要素でフォールバック不可。object はフォールバックコンテンツを子要素として持てる
・<embed> ― 外部コンテンツを埋め込む空要素。フォールバックを持てない
・<object> ― 外部リソースを埋め込む要素。フォールバックコンテンツを子要素として持てる 
<!-- embed：空要素（フォールバックなし） -->
<embed src="document.pdf"
       type="application/pdf"
       width="800"
       height="600">

<!-- object：フォールバックコンテンツを持てる -->
<object data="document.pdf"
        type="application/pdf"
        width="800"
        height="600">
  <!-- 表示できない場合のフォールバック -->
  <p>PDFを表示できません。
    <a href="document.pdf">ダウンロード</a>
  </p>
</object>
✅ embed と object の違い
・embed：空要素。フォールバックコンテンツを持てない。src 属性でURLを指定
・object：フォールバックコンテンツを子要素として持てる。data 属性でURLを指定
属性embedobject
URLの指定srcdata
type✅ MIMEタイプ✅ MIMEタイプ
width / height✅✅
フォールバック❌ 持てない（空要素）✅ 子要素として持てる

⑦ map 要素 / area 要素

重要ポイント⑦：map と area でイメージマップを定義。img の usemap 属性で map の name を参照する
・<map> と <area> はイメージマップ（画像の特定領域をリンクにする）を定義します
・<img> の usemap 属性で <map> の name 属性を参照します
・<area> は空要素で、クリック可能な領域の形状・座標・リンク先を指定します 
<img src="japan-map.png"
     alt="日本地図"
     usemap="#japanmap"
     width="600"
     height="400">

<map name="japanmap">
  <!-- 矩形（左上x,y・右下x,y） -->
  <area shape="rect"
        coords="100,50,200,150"
        href="tokyo.html"
        alt="東京">
  <!-- 円形（中心x,y・半径） -->
  <area shape="circle"
        coords="300,200,50"
        href="osaka.html"
        alt="大阪">
  <!-- 多角形（x1,y1,x2,y2,...） -->
  <area shape="poly"
        coords="400,100,450,150,420,200"
        href="nagoya.html"
        alt="名古屋">
</map>

area shape 属性 インタラクティブデモ

shape を選択して、coords 属性の形式と描画イメージを確認しましょう。

shape 属性の値coords 属性の形式説明
