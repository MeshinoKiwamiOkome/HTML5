📡 デバイスアクセスAPI 学習サンプル

HTML5で追加されたデバイスアクセス系APIの概要と使い方を学びましょう。 位置情報・デバイスの傾き・タッチ・ポインター・各種入力イベントを扱います。

① Geolocation API

重要ポイント①：Geolocation APIではユーザーの位置情報・精度・方角・速度などを取得できる
Geolocation APIは navigator.geolocation を通じて利用します。 GPS・Wi-Fi・基地局などを組み合わせてユーザーの現在地を取得し、 緯度・経度・精度・高度・方角・速度などの情報を GeolocationCoordinates オブジェクトとして返します。 プライバシー保護のため、ユーザーの許可が必須です。

取得できる位置情報の種類

latitude
緯度（度）。北緯がプラス、南緯がマイナス
longitude
経度（度）。東経がプラス、西経がマイナス
accuracy
位置の精度（メートル）。値が小さいほど高精度
altitude
高度（メートル）。取得できない場合は null
heading
方角（度）。真北が0°、時計回りに増加。取得できない場合は null
speed
速度（m/s）。取得できない場合は null

主なメソッド

メソッド説明備考
getCurrentPosition(success, error, options) 現在位置を1回だけ取得する 非同期。成功時に success コールバックが呼ばれる
watchPosition(success, error, options) 位置の変化を継続的に監視する 監視IDを返す。移動中のリアルタイム追跡に使用
clearWatch(id) watchPosition の監視を停止する watchPosition が返した ID を渡す

options オブジェクトのプロパティ

プロパティ型説明
enableHighAccuracy boolean true にするとGPSなどを使い高精度な位置情報を要求する（消費電力増）
timeout number（ms） 位置情報取得のタイムアウト時間。超過するとエラーコールバックが呼ばれる
maximumAge number（ms） キャッシュされた位置情報の最大有効期間。0 は常に最新を取得 
/* Geolocation APIの利用可否チェック */
if ('geolocation' in navigator) {

  /* 現在位置を1回取得 */
  navigator.geolocation.getCurrentPosition(
    /* 成功コールバック */
    (position) => {
      const coords = position.coords;
      console.log('緯度:',   coords.latitude);   /* 緯度 */
      console.log('経度:',   coords.longitude);  /* 経度 */
      console.log('精度:',   coords.accuracy);   /* 精度（m） */
      console.log('高度:',   coords.altitude);   /* 高度（m）または null */
      console.log('方角:',   coords.heading);    /* 方角（度）または null */
      console.log('速度:',   coords.speed);      /* 速度（m/s）または null */
      console.log('取得時刻:', position.timestamp); /* タイムスタンプ（ms） */
    },
    /* エラーコールバック */
    (error) => {
      switch (error.code) {
        case error.PERMISSION_DENIED:     /* ユーザーが拒否 */
        case error.POSITION_UNAVAILABLE:  /* 位置情報取得不可 */
        case error.TIMEOUT:              /* タイムアウト */
      }
    },
    /* オプション */
    {
      enableHighAccuracy: true,   /* 高精度モード */
      timeout:            10000,  /* 10秒でタイムアウト */
      maximumAge:         0       /* キャッシュ不使用 */
    }
  );

  /* 位置の変化を継続監視 */
  const watchId = navigator.geolocation.watchPosition(
    (position) => { console.log(position.coords); }
  );

  /* 監視を停止 */
  navigator.geolocation.clearWatch(watchId);
}

⚠️ Geolocation API の注意点
・ユーザーの許可が必須です。許可なしに位置情報を取得することはできません
・HTTPS（セキュアコンテキスト）でのみ動作します（HTTP では利用不可）
・altitude・heading・speed はデバイスが対応していない場合 null になります
・heading は移動中でないと取得できない場合があります（静止時は null または NaN）

② DeviceOrientation / DeviceMotion API

重要ポイント②：Device Orientation Eventでデバイスの傾き・方角・加速度・回転速度などを取得できる
deviceorientation イベントはデバイスの傾き（alpha / beta / gamma）と 方角を、 devicemotion イベントは加速度と回転速度（ジャイロスコープ）を 取得します。スマートフォン・タブレットのセンサーを利用します。

deviceorientation イベントのプロパティ

プロパティ説明範囲
alpha Z軸周りの回転角（コンパス方位）。真北が0° 0° 〜 360°
beta X軸周りの回転角（前後の傾き）。水平が0°、前傾きがプラス -180° 〜 180°
gamma Y軸周りの回転角（左右の傾き）。水平が0°、右傾きがプラス -90° 〜 90°
absolute 地球の座標系に対する絶対角度かどうか（true/false） boolean

devicemotion イベントのプロパティ

プロパティ説明
acceleration 重力を除いた加速度（x / y / z 軸、m/s²）
accelerationIncludingGravity 重力を含む加速度（x / y / z 軸、m/s²）
rotationRate 回転速度（alpha / beta / gamma 軸、deg/s）。ジャイロスコープの値
interval イベントの発火間隔（ms） 
/* deviceorientation：デバイスの傾き・方角を取得 */
window.addEventListener('deviceorientation', (event) => {
  console.log('alpha（方位）:', event.alpha);  /* 0〜360° コンパス方位 */
  console.log('beta（前後傾き）:', event.beta);   /* -180〜180° */
  console.log('gamma（左右傾き）:', event.gamma); /* -90〜90° */
  console.log('絶対角度:', event.absolute);         /* true/false */
});

/* devicemotion：加速度・回転速度を取得 */
window.addEventListener('devicemotion', (event) => {
  const acc = event.acceleration;
  console.log('加速度 X:', acc.x);  /* m/s² */
  console.log('加速度 Y:', acc.y);
  console.log('加速度 Z:', acc.z);

  const rot = event.rotationRate;
  console.log('回転速度 alpha:', rot.alpha); /* deg/s */
  console.log('回転速度 beta:',  rot.beta);
  console.log('回転速度 gamma:', rot.gamma);
});

③ Touch Events

重要ポイント③：イベントで扱える入力デバイスにタッチ・ペン・マウスがある
Touch Events はタッチスクリーンへの指・スタイラスによる操作を扱うAPIです。 マルチタッチ（複数の指による同時操作）に対応しており、 各タッチ点の座標・識別子・対象要素などを取得できます。

Touch Events の種類

イベント発生タイミング
touchstart指がタッチスクリーンに触れた時
touchmove指がタッチスクリーン上を移動している時（連続発火）
touchend指がタッチスクリーンから離れた時
touchcancelタッチが中断された時（電話着信など）

TouchEvent のプロパティ

プロパティ説明
touches現在画面に触れているすべてのタッチ点のリスト
targetTouchesイベント対象要素上のタッチ点のリスト
changedTouches今回のイベントで変化したタッチ点のリスト

Touch オブジェクトの主なプロパティ

identifier
タッチ点を識別するID。マルチタッチで各指を区別するために使う
clientX / clientY
ビューポート（表示領域）基準の座標
pageX / pageY
ページ全体基準の座標（スクロール量を含む）
screenX / screenY
画面（スクリーン）基準の座標
target
タッチが開始された要素
radiusX / radiusY
タッチ領域の半径（楕円形）。対応デバイスのみ
const area = document.getElementById('touchArea');

/* touchstart：タッチ開始 */
area.addEventListener('touchstart', (e) => {
  e.preventDefault(); /* スクロールなどのデフォルト動作を抑制 */

  /* changedTouches：今回変化したタッチ点 */
  [...e.changedTouches].forEach(touch => {
    console.log('ID:',      touch.identifier); /* タッチ点のID */
    console.log('X座標:',  touch.clientX);
    console.log('Y座標:',  touch.clientY);
  });
});

/* touchmove：タッチ移動 */
area.addEventListener('touchmove', (e) => {
  e.preventDefault();
  console.log('タッチ数:', e.touches.length); /* 現在の指の数 */
});

/* touchend：タッチ終了 */
area.addEventListener('touchend', (e) => {
  console.log('離れた指:', e.changedTouches.length);
});

④ Pointer Events

重要ポイント：Pointer Eventsはタッチ・ペン・マウスを統一的に扱うイベントモデルである
Pointer Events は マウス・タッチ・スタイラスペン という 異なる入力デバイスを統一されたイベントモデルで扱えるAPIです。 pointerType プロパティで入力デバイスの種類を判別できます。 Touch Events と Mouse Events を個別に実装する必要がなくなります。

Pointer Events の種類

イベント説明対応するマウスイベント
pointerdownポインターが押された時mousedown / touchstart
pointermoveポインターが移動した時mousemove / touchmove
pointerupポインターが離された時mouseup / touchend
pointerenterポインターが要素に入った時mouseenter
pointerleaveポインターが要素から出た時mouseleave
pointercancelポインター操作が中断された時touchcancel
gotpointercaptureポインターキャプチャ取得時—
lostpointercaptureポインターキャプチャ解放時—

PointerEvent の主なプロパティ

pointerType
"mouse"・"touch"・"pen" の3種類。入力デバイスを判別できる
pointerId
ポインターを識別するID。マルチタッチで各指を区別
pressure
筆圧（0〜1）。ペンタブレットなどで利用
tiltX / tiltY
ペンの傾き角度（度）。スタイラスペン向け
width / height
接触領域の幅・高さ（px）
isPrimary
マルチタッチ時の主ポインターかどうか（boolean）
const el = document.getElementById('myElement');

/* Pointer Events：タッチ・ペン・マウスを統一処理 */
el.addEventListener('pointerdown', (e) => {
  console.log('入力デバイス:', e.pointerType); /* "mouse" / "touch" / "pen" */
  console.log('ポインターID:', e.pointerId);
  console.log('X座標:',      e.clientX);
  console.log('Y座標:',      e.clientY);
  console.log('筆圧:',       e.pressure);    /* 0〜1（ペンタブ向け） */
  console.log('主ポインター:', e.isPrimary);

  /* pointerType による分岐処理 */
  if (e.pointerType === 'touch') {
    console.log('タッチ操作');
  } else if (e.pointerType === 'pen') {
    console.log('ペン操作 筆圧:', e.pressure);
  } else {
    console.log('マウス操作');
  }
});

el.addEventListener('pointermove', (e) => {
  console.log('移動:', e.clientX, e.clientY);
});

⑤ DOM3 Events（UI Events）

重要ポイント：DOM3 Eventsはキーボード・マウス・フォーカスなどのUIイベントを定義する仕様である
DOM3 Events（現在は UI Events 仕様として管理）は、 Webブラウザにおけるキーボード・マウス・フォーカス・入力・ホイールなどの UIイベントの動作を標準化した仕様です。 イベントの伝播（バブリング・キャプチャリング）モデルも定義しています。

主なUIイベントの種類

カテゴリイベント名説明
マウス click クリック（mousedown + mouseup）
dblclick ダブルクリック
mousemove マウスポインターが移動した時
mouseenter / mouseleave 要素に入った・出た時（バブリングなし）
キーボード keydown キーが押された時（最初に発火）
keyup キーが離された時
keypress 文字キーが押された時（非推奨。keydown を使うこと）
フォーカス focus / blur フォーカスを得た・失った時（バブリングなし）
focusin / focusout フォーカスを得た・失った時（バブリングあり）
入力・変更 input 入力値が変化した時（リアルタイム）
change 入力値が確定した時（フォーカスを失った時など）
ホイール wheel マウスホイールが回転した時

イベント伝播（バブリング・キャプチャリング）

/* イベント伝播の3フェーズ */
/* 1. キャプチャリングフェーズ：ルートから対象要素へ向かって伝播 */
/* 2. ターゲットフェーズ：対象要素でイベント発火 */
/* 3. バブリングフェーズ：対象要素からルートへ向かって伝播 */

/* addEventListener の第3引数でフェーズを指定 */
el.addEventListener('click', handler, false); /* バブリングフェーズ（デフォルト） */
el.addEventListener('click', handler, true);  /* キャプチャリングフェーズ */

/* イベント伝播の停止 */
el.addEventListener('click', (e) => {
  e.stopPropagation();    /* 伝播を停止（他のリスナーは実行される） */
  e.stopImmediatePropagation(); /* 伝播を即時停止（他のリスナーも実行されない） */
  e.preventDefault();     /* デフォルト動作を抑制（リンク遷移など） */
});

/* キーボードイベントの例 */
document.addEventListener('keydown', (e) => {
  console.log('key:',     e.key);      /* キーの値（'a', 'Enter' など） */
  console.log('code:',    e.code);     /* 物理キーコード（'KeyA', 'Enter' など） */
  console.log('ctrlKey:', e.ctrlKey);  /* Ctrlキーが押されているか */
  console.log('shiftKey:',e.shiftKey); /* Shiftキーが押されているか */
});

⑥ Generic Sensor API

重要ポイント：Generic Sensor APIは各種センサーを統一されたインターフェースで扱うAPIである
Generic Sensor APIは、加速度計・ジャイロスコープ・磁力計などの デバイスセンサーを統一されたインターフェース（Sensor基底クラス）で扱うAPIです。 DeviceOrientation イベントよりも低レベルで柔軟な制御が可能です。 HTTPS（セキュアコンテキスト）でのみ利用できます。

Generic Sensor API の主なセンサークラス

Accelerometer
重力を含む加速度（x / y / z 軸、m/s²）を取得
LinearAccelerationSensor
重力を除いた加速度（x / y / z 軸、m/s²）を取得
Gyroscope
回転速度（x / y / z 軸、rad/s）を取得。ジャイロスコープ
Magnetometer
磁場の強さ（x / y / z 軸、μT）を取得。コンパスに利用
AbsoluteOrientationSensor
地球座標系に対するデバイスの絶対的な向きを四元数で取得
RelativeOrientationSensor
地磁気を考慮しないデバイスの相対的な向きを四元数で取得

Sensor 基底クラスの共通インターフェース

種別名前説明
メソッドstart()センサーの計測を開始する
メソッドstop()センサーの計測を停止する
プロパティactivatedセンサーが動作中かどうか（boolean）
プロパティhasReading最新の読み取り値があるかどうか（boolean）
プロパティtimestamp最新の読み取り時刻（ms）
イベントreading新しい値が取得された時に発火
イベントactivateセンサーが起動した時に発火
イベントerrorエラー発生時に発火
 
/* Accelerometer（加速度計）の使用例 */
try {
  const sensor = new Accelerometer({ frequency: 60 }); /* 60Hz で計測 */

  sensor.addEventListener('reading', () => {
    console.log('X軸加速度:', sensor.x); /* m/s² */
    console.log('Y軸加速度:', sensor.y);
    console.log('Z軸加速度:', sensor.z);
  });

  sensor.addEventListener('error', (e) => {
    console.log('エラー:', e.error.name, e.error.message);
  });

  sensor.start(); /* 計測開始 */

} catch (e) {
  if (e.name === 'SecurityError') {
    console.log('センサーへのアクセスが拒否されました');
  } else if (e.name === 'ReferenceError') {
    console.log('このブラウザはAccelerometerをサポートしていません');
  }
}

/* Gyroscope（ジャイロスコープ）の使用例 */
const gyro = new Gyroscope({ frequency: 30 });
gyro.addEventListener('reading', () => {
  console.log('回転速度 X:', gyro.x); /* rad/s */
  console.log('回転速度 Y:', gyro.y);
  console.log('回転速度 Z:', gyro.z);
});
gyro.start();

Touch Events タッチスクリーンへの操作を扱うイベント touchstart / touchmove / touchend / touchcancel。マルチタッチ対応
Pointer Events タッチ・ペン・マウスを統一したイベントモデル pointerType で "mouse" / "touch" / "pen" を判別。pressure で筆圧取得
DOM3 Events（UI Events） キーボード・マウス・フォーカスなどのUIイベント仕様 イベント伝播（バブリング・キャプチャリング）を定義。focus はバブリングなし
Generic Sensor API 各種センサーを統一インターフェースで扱うAPI Sensor基底クラスを継承。start() / stop()。frequency でサンプリングレート指定可
