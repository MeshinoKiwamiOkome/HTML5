margin・padding・border・box-sizing・border-radius・box-shadow・position・float・display・visibility・overflow など、CSSボックスモデルに関するプロパティを学びましょう。

① ボックスモデルの基本構造

重要ポイント③：幅と高さの適用される領域は box-sizing プロパティで設定する
CSSのすべての要素は「ボックス」として扱われます。ボックスは外側から margin（余白）→ border（枠線）→ padding（内側余白）→ content（内容） の4層で構成されています。

ボックスモデル図

margin（外側余白）
border（枠線）
padding（内側余白）
content（内容領域）
width / height が適用される
/* box-sizing: content-box（デフォルト） */
/* width/height = コンテンツ領域のみ */
.box {
  width: 200px;
  padding: 20px;
  border: 5px solid #9f7aea;
  /* 実際の表示幅 = 200 + 20×2 + 5×2 = 250px */
  box-sizing: content-box; /* デフォルト値 */
}

/* box-sizing: border-box */
/* width/height = border + padding + content を含む全体 */
.box {
  width: 200px;
  padding: 20px;
  border: 5px solid #9f7aea;
  /* 実際の表示幅 = 200px（指定した値そのまま） */
  box-sizing: border-box;
}

/* 全要素に border-box を適用する慣習的な書き方 */
*, *::before, *::after {
  box-sizing: border-box;
}

② margin（外側余白）

ポイント
margin は要素の外側の余白を指定します。 隣接するブロック要素の上下 margin はマージンの相殺（折りたたみ）が発生します。 
/* 個別指定 */
margin-top:    16px;
margin-right:  8px;
margin-bottom: 16px;
margin-left:   8px;

/* ショートハンド（時計回り：上 右 下 左） */
margin: 16px 8px 16px 8px;  /* 上 右 下 左 */
margin: 16px 8px;           /* 上下16px・左右8px */
margin: 16px;               /* 全方向16px */
margin: 16px 8px 4px;       /* 上16px・左右8px・下4px */

/* 水平方向の中央揃え */
margin: 0 auto;  /* ブロック要素を中央揃え（width指定が必要） */

/* 負のマージン */
margin-top: -10px; /* 要素を上方向に引き上げる */
⚠️ マージンの相殺（Margin Collapsing）
隣接するブロック要素の上下 margin は大きい方の値に折りたたまれます。
例：上の要素の margin-bottom: 20px と下の要素の margin-top: 30px が隣接すると、 間隔は 30px（大きい方）になります。
※ 左右 margin・flex/grid コンテナ内では相殺は発生しません。
値説明
autoブラウザが自動計算（水平中央揃えに使用）
長さ（px, em など）固定値で余白を指定
パーセント（%）親要素の 幅 に対する割合（上下も幅基準）
負の値要素を引き寄せる・重ねる効果

③ padding（内側余白）

ポイント
padding は要素の内側の余白（コンテンツと border の間）を指定します。 margin と異なり、負の値は指定できません。 また、背景色・背景画像は padding 領域まで広がります。 
/* 個別指定 */
padding-top:    12px;
padding-right:  24px;
padding-bottom: 12px;
padding-left:   24px;

/* ショートハンド（時計回り：上 右 下 左） */
padding: 12px 24px;       /* 上下12px・左右24px */
padding: 8px 16px 12px;  /* 上8px・左右16px・下12px */
padding: 8px;             /* 全方向8px */

⑧ position（配置方法）

ポイント
position プロパティで要素の配置方法を指定します。 static 以外の値を指定した要素は「位置指定要素」となり、 top / right / bottom / left / z-index が有効になります。 
/* static（デフォルト）：通常のフロー */
position: static;   /* top/left等は無効 */

/* relative：通常の位置を基準にずらす */
position: relative;
top: 10px;   /* 通常位置から10px下にずれる */
left: 20px;  /* 通常位置から20px右にずれる */
/* ※ 元の場所にスペースは残る */

/* absolute：最も近い「位置指定された祖先要素」を基準に配置 */
position: absolute;
top: 0;
right: 0;
/* ※ 通常フローから外れる（スペースを占有しない） */

/* fixed：ビューポートを基準に固定 */
position: fixed;
bottom: 20px;
right: 20px;
/* ※ スクロールしても動かない */

/* sticky：スクロール位置に応じてrelativeとfixedを切り替え */
position: sticky;
top: 0;
/* ※ スクロールで閾値に達するとfixedのように固定される */

⑩ float / clear

ポイント
float は要素を左右に寄せ、後続のインライン要素（テキストなど）が その周りに回り込みます。現在はレイアウトに Flexbox / Grid が主流ですが、 テキストの回り込みには今も使われます。 
float: left;   /* 左に寄せる（テキストが右に回り込む） */
float: right;  /* 右に寄せる（テキストが左に回り込む） */
float: none;   /* 回り込みなし（デフォルト） */

/* clear：回り込みを解除する */
clear: left;   /* 左のfloatを解除 */
clear: right;  /* 右のfloatを解除 */
clear: both;   /* 両方のfloatを解除 */
clear: none;   /* 解除しない（デフォルト） */

/* clearfix：floatによる親要素の高さ崩れを防ぐ */
.clearfix::after {
  content: "";
  display: block;
  clear: both;
}

float: left のデモ

float: left

float: left を指定した要素の右側にテキストが回り込みます。 画像とテキストを並べるレイアウトに使われてきました。 現在は Flexbox や Grid が主流ですが、テキストの回り込みには今も有効です。 float を解除するには clear プロパティを使います。

float: right のデモ

float: right

float: right を指定した要素の左側にテキストが回り込みます。 clear: both を指定した要素は、float の影響を受けずに float 要素の下に配置されます。
