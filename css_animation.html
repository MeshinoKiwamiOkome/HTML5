✨ CSS アニメーション 学習サンプル

transform・transition・animation・@keyframes など、 CSSで動きを表現するプロパティを学びましょう。

① transform プロパティ

重要ポイント①：transform 関連プロパティでは、ボックスの回転・拡大縮小・移動などを行う
transform は要素の見た目の変形を行います。 レイアウトには影響せず（周囲の要素は動かない）、 GPU アクセラレーションが効くため滑らかに動作します。

transform 関数の種類

rotate(45deg)
scale(1.5)
scaleX(1.8)
translateX(20px)
translateY(-16px)
skewX(20deg)
skewY(20deg)
rotate + scale
/* 移動 */
transform: translateX(20px);          /* X軸方向に20px移動 */
transform: translateY(-30px);         /* Y軸方向に-30px移動（上へ） */
transform: translate(20px, -30px);   /* X・Y同時指定 */

/* 回転 */
transform: rotate(45deg);            /* 時計回りに45度回転 */
transform: rotate(-90deg);           /* 反時計回りに90度回転 */
transform: rotate(0.5turn);          /* 半回転（180度） */

/* 拡大縮小 */
transform: scale(1.5);              /* 1.5倍に拡大 */
transform: scale(0.8);              /* 0.8倍に縮小 */
transform: scaleX(2);               /* 横方向のみ2倍 */
transform: scaleY(0.5);             /* 縦方向のみ0.5倍 */
transform: scale(1.2, 0.8);         /* X・Y個別指定 */

/* 傾斜（スキュー） */
transform: skewX(20deg);            /* X軸方向に傾ける */
transform: skewY(10deg);            /* Y軸方向に傾ける */
transform: skew(20deg, 10deg);      /* X・Y同時指定 */

/* 複数の変形を同時指定（スペース区切り・左から順に適用） */
transform: rotate(30deg) scale(1.3);
transform: translateX(20px) rotate(45deg);

/* 変形なし */
transform: none;

⚠️ transform の注意点
・transform は要素の見た目だけを変形し、 レイアウト上の位置・サイズは変わりません
・複数の変形を指定するときはスペース区切りで並べます （カンマ区切りは不可）
・適用順序は左から右の順番で、順番によって結果が変わります

③ CSS トランジションとは

重要ポイント②：トランジションは、値の切り替わりをなめらかに連続した動きで見せる機能
例えば :hover で色が変わるとき、 瞬時に切り替わるのではなく指定した時間をかけてなめらかに変化させます。 「開始状態」と「終了状態」の2点間を補間するシンプルな仕組みです。
transition なし（ホバーしてみて）
ホバー
transition あり（ホバーしてみて）
ホバー 
/* トランジションの基本 */
.button {
  background: #9f7aea;
  transition: background 0.3s ease;
}
.button:hover {
  background: #f6ad55;  /* 0.3秒かけてなめらかに変化 */
}

④ transition-property プロパティ

/* どのプロパティにトランジションを適用するか */
transition-property: all;             /* すべてのプロパティ */
transition-property: none;            /* トランジションなし */
transition-property: background-color; /* 背景色のみ */
transition-property: transform;       /* 変形のみ */
transition-property: background-color, transform, opacity; /* 複数指定 */
✅ transition-property の使い分け
・all は手軽ですが、意図しないプロパティにも適用されパフォーマンスに影響する場合があります
・transform と opacity は GPU アクセラレーションが効き、 最もパフォーマンスが良いプロパティです
・アニメーションさせたいプロパティを明示的に指定するのがベストプラクティスです

⑤ transition-duration プロパティ

/* トランジションにかける時間 */
transition-duration: 0s;     /* 即時（デフォルト） */
transition-duration: 0.3s;   /* 0.3秒 */
transition-duration: 500ms;  /* 500ミリ秒（= 0.5s） */
transition-duration: 2s;     /* 2秒 */

/* 複数プロパティに異なる時間を指定 */
transition-property: background-color, transform;
transition-duration: 0.3s, 0.5s;  /* background:0.3s / transform:0.5s */

⑥ transition-timing-function プロパティ

/* 変化の速度カーブを指定 */
transition-timing-function: ease;         /* ゆっくり始まり→速く→ゆっくり終わる（デフォルト） */
transition-timing-function: linear;       /* 一定速度 */
transition-timing-function: ease-in;      /* ゆっくり始まり→速く終わる */
transition-timing-function: ease-out;     /* 速く始まり→ゆっくり終わる */
transition-timing-function: ease-in-out;  /* ゆっくり始まり→速く→ゆっくり終わる（easeより対称的） */
transition-timing-function: steps(4);     /* 4段階でジャンプ */
transition-timing-function: cubic-bezier(0.25, 0.1, 0.25, 1.0); /* カスタム曲線 */

⑦ transition-delay プロパティ

/* トランジション開始までの遅延時間 */
transition-delay: 0s;     /* 遅延なし（デフォルト） */
transition-delay: 0.5s;   /* 0.5秒後に開始 */
transition-delay: -0.2s;  /* 負の値：アニメーションの途中から開始 */
⚠️ transition-delay の負の値
負の値を指定すると、アニメーションが途中から始まったように見えます。
例：duration: 1s・delay: -0.5s → アニメーションの 0.5s 経過した時点から開始

transition: transform 0.5s ease-out 0.1s;

/* 複数プロパティ：カンマ区切り */
transition:
  background-color 0.3s ease,
  transform 0.5s ease-out 0.1s,

⑨ CSS アニメーションとは

重要ポイント③：アニメーションは、キーフレームでトランジションを連続実行させるようなもの
トランジションが「開始→終了」の2点間の変化なのに対し、 アニメーションは @keyframes で複数の中間状態（キーフレーム）を定義し、 それらをつなぎ合わせて連続した動きを作ります。 トリガー（ホバーなど）不要で自動再生でき、繰り返しも可能です。
トランジション
  • 開始・終了の2点間
  • トリガーが必要（:hover など）
  • 自動繰り返し不可
  • 逆再生は自動
→
アニメーション
  • 複数のキーフレームを定義
  • トリガー不要（自動再生）
  • 繰り返し・無限ループ可能
  • 再生方向・一時停止も制御可

⑩ @keyframes

/* @keyframes：アニメーションの各時点の状態を定義 */
@keyframes アニメーション名 {
  from { transform: translateX(0); }    /* 開始（= 0%） */
  to   { transform: translateX(100px); } /* 終了（= 100%） */
}

/* パーセントで中間状態を細かく定義 */
@keyframes bounce {
  0%   { transform: translateY(0); }
  50%  { transform: translateY(-40px); }
  100% { transform: translateY(0); }
}

/* 複数のプロパティを同時に変化させる */
@keyframes fadeIn {
  from {
    opacity: 0;
    transform: translateY(20px);
  }
  to {
    opacity: 1;
    transform: translateY(0);
  }
}

/* 複数のキーフレームを同じ状態にまとめる */
@keyframes flash {
  0%, 100% { opacity: 1; }
  50%       { opacity: 0; }
}

⑪ animation-name / animation-duration

/* animation-name：@keyframes の名前を指定 */
animation-name: bounce;        /* @keyframes bounce を適用 */
animation-name: none;          /* アニメーションなし */
animation-name: bounce, spin;  /* 複数のアニメーションを同時に適用 */

/* animation-duration：1サイクルにかける時間 */
animation-duration: 0s;     /* 即時（デフォルト・実質アニメーションなし） */
animation-duration: 1s;     /* 1秒 */
animation-duration: 500ms;  /* 500ミリ秒 */
animation-duration: 3s;     /* 3秒 */

⑫ animation-timing-function / animation-delay

/* animation-timing-function：速度カーブ（transition と同じ値） */
animation-timing-function: ease;         /* デフォルト */
animation-timing-function: linear;
animation-timing-function: ease-in;
animation-timing-function: ease-out;
animation-timing-function: ease-in-out;
animation-timing-function: steps(4, end); /* 4段階でジャンプ */
animation-timing-function: cubic-bezier(0.68, -0.55, 0.27, 1.55); /* バウンス */

/* animation-delay：開始までの遅延時間 */
animation-delay: 0s;     /* 遅延なし（デフォルト） */
animation-delay: 1s;     /* 1秒後に開始 */
animation-delay: -0.5s;  /* アニメーションの0.5s経過した時点から開始 */

⑬ animation-iteration-count / animation-direction

/* animation-iteration-count：繰り返し回数 */
animation-iteration-count: 1;        /* 1回（デフォルト） */
animation-iteration-count: 3;        /* 3回繰り返す */
animation-iteration-count: infinite; /* 無限ループ */
animation-iteration-count: 2.5;      /* 2.5回（小数も可） */

/* animation-direction：再生方向 */
animation-direction: normal;            /* 順方向（デフォルト）: 0%→100% */
animation-direction: reverse;           /* 逆方向: 100%→0% */
animation-direction: alternate;         /* 交互: 順→逆→順→逆… */
animation-direction: alternate-reverse; /* 交互（逆から）: 逆→順→逆→順… */

animation-direction の違いを視覚で確認

normal（0%→100%）
reverse（100%→0%）
alternate（順↔逆）
alternate-reverse

⑭ animation-play-state / animation-fill-mode

/* animation-play-state：再生・一時停止 */
animation-play-state: running; /* 再生中（デフォルト） */
animation-play-state: paused;  /* 一時停止 */

/* ホバーで一時停止する例 */
.box        { animation: spin 2s linear infinite; }
.box:hover  { animation-play-state: paused; }

/* animation-fill-mode：アニメーション前後のスタイルを指定 */
animation-fill-mode: none;      /* 前後ともアニメーション外のスタイル（デフォルト） */
animation-fill-mode: forwards;  /* 終了後：最後のキーフレームのスタイルを維持 */
animation-fill-mode: backwards; /* 開始前（delay中）：最初のキーフレームのスタイルを適用 */
animation-fill-mode: both;      /* forwards と backwards の両方 */

animation-play-state デモ（ホバーで一時停止）

ホバーで animation-play-state: paused

animation-fill-mode の違い

none（デフォルト）
前後ともアニメーション外のスタイル
forwards
終了後：最後のキーフレームを維持
backwards
delay中：最初のキーフレームを適用
both
forwards + backwards の両方

⑮ animation プロパティ（ショートハンド）

/* animation: name duration timing-function delay iteration-count direction fill-mode play-state */
animation: bounce 1s ease 0s infinite normal none running;

/* よく使う省略形 */
animation: bounce 1s ease infinite;
animation: spin 2s linear infinite;
animation: fadeIn 0.5s ease-out forwards;
animation: pulse 1.2s ease-in-out infinite alternate;

/* 複数のアニメーションを同時に適用（カンマ区切り） */
animation:
  spin   2s linear   infinite,
  color  3s ease     infinite;

Q7. 記述問題

animation-fill-mode の4つの値（none・forwards・ backwards・both）の違いを、 「アニメーション開始前（delay中）」と「アニメーション終了後」の 2つの観点から説明してください。
