① CSSの指定元による優先順位

重要ポイント①：通常は製作者 > ユーザー > UA。!important で逆転する
CSSは3つの「指定元（オリジン）」から適用されます。

⚠️ 試験重要ポイント①：!important で優先順位が逆転する

通常：製作者 > ユーザー > ユーザーエージェント
!important 付き：ユーザーエージェント > ユーザー > 製作者（逆転！）

ユーザーの !important が製作者より優先されるのはアクセシビリティのためです。
✅ 覚え方のポイント
・通常時：製作者が最優先（Webサイトのデザインを優先）
・!important 付き：逆転してユーザーエージェント > ユーザー > 製作者の順になる
・ユーザーの !important が製作者より優先されるのはアクセシビリティのため

② !important で優先順位を高くする

/* !important の書き方 */
p {
    color: red !important;   /* 値の後に !important */
    font-size: 16px;           /* こちらは通常の宣言 */
}

/* 詳細度が低くても !important で勝てる例 */
p       { color: blue; }           /* 詳細度 0-0-1 */
#main p { color: green; }          /* 詳細度 1-0-1（高い） */
p       { color: red !important; } /* !important → 赤が適用 */

/* !important 同士が競合した場合は詳細度で決まる */
p       { color: red  !important; } /* 詳細度 0-0-1 */
.text p { color: blue !important; } /* 詳細度 0-1-1 → 青が適用 */

/* 同じ詳細度の場合は後に書いた方が優先 */
p { color: red; }    /* ← 上書きされる */
p { color: blue; }   /* ← 後に書いた方が適用 */

⚠️ !important の注意点
・多用すると CSS の管理が複雑になります
・上書きするにはさらに !important が必要になり「!important 地獄」になりがちです
・使用は最小限にとどめ、詳細度の設計で解決するのが推奨です

③ セレクタの詳細度による優先順位の計算方法

重要ポイント②③：詳細度は A-B-C の3桁。style属性は別格（最高）
・詳細度が最も高いのは style 属性による指定（インラインスタイル）
・セレクタの詳細度は IDセレクタ（A）・属性系セレクタ（B）・要素系セレクタ（C）の3桁で示します

詳細度の4段階（高い順）

最高 style 属性（インラインスタイル） 1-0-0-0
高 IDセレクタ（#id） A桁 +1
中 クラス・属性・擬似クラスセレクタ B桁 +1
低 要素・擬似要素セレクタ C桁 +1

⚠️ 詳細度の比較は左の桁（ID）から順に比較する

#id（1-0-0）vs .a.b.c.d.e.f.g.h.i.j.k（0-11-0）

④ 優先順位の総まとめ（高い順）

①最高 ユーザーエージェントの !important 逆転
② ユーザーの !important 逆転
③ 製作者の !important ↑ !important
④ 製作者：style 属性（インライン） 詳細度最高
⑤ 製作者：IDセレクタ（#id） A桁
⑥ 製作者：クラス・属性・擬似クラス B桁
⑦ 製作者：要素・擬似要素 C桁
⑧ ユーザーの通常CSS
⑨最低 ユーザーエージェントの通常CSS 最低

Q6. コード穴埋め問題

__A__ 〜 __E__ に適切な詳細度・値・説明を入力してください。

/* A：このセレクタの詳細度は？ */
#nav .menu li a:hover { color: red; }
/* 詳細度 → __A__ */

/* B：このセレクタの詳細度は？ */
.card.active::before { content: "★"; }
/* 詳細度 → __B__ */

/* C：!importantで優先順位を上げる書き方 */
p { color: blue __C__; }

/* D：詳細度に影響しないセレクタ */
__D__ { box-sizing: border-box; }

/* E：製作者CSSの中で詳細度が最も高い指定方法 */
<p __E__="color: red;">テキスト</p>

優先順位内容重要ポイント
指定元（通常） 製作者 > ユーザー > UA 製作者のCSSが最優先
指定元（!important） UA !important > ユーザー !important > 製作者 !important !important で逆転。アクセシビリティのため
style 属性 詳細度 1-0-0-0（別格） 製作者CSSの中で最高詳細度
詳細度 A桁 IDセレクタ（#id） 1IDにつき +1

詳細度 C桁 要素セレクタ・擬似要素 1つにつき +1
