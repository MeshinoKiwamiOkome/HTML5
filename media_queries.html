📡 メディアクエリ（Media Queries）

デバイスの特性に応じてCSSを切り替えるメディアクエリの書き方・ メディア型・メディア特性・論理演算子を学びましょう。

① メディアクエリとは

重要ポイント①：メディアクエリには、HTMLの media 属性で指定する方法と、CSSで @media を使う方法がある
メディアクエリとは、デバイスの種類・画面幅・解像度などのメディアの特性を条件として、 適用するCSSを切り替える仕組みです。 CSS3 で導入され、レスポンシブWebデザインの中核技術となっています。

メディアクエリの基本構文

@media screen メディア型 and 論理演算子 (min-widthメディア特性 : 768px値) {
   .container { width: 750px; }
}

2つの指定方法

方法① HTML の media 属性で指定

<!-- link要素のmedia属性 -->
<link rel="stylesheet" href="style.css"
      media="screen and (max-width: 600px)">

<!-- style要素のmedia属性 -->
<style media="print">
  body { font-size: 12pt; }
</style>

<!-- source要素のmedia属性（picture要素内） -->
<picture>
  <source srcset="large.jpg" media="(min-width: 769px)">
  <img src="small.jpg" alt="画像">
</picture>

方法② CSS の @media で指定

/* CSSファイル内に直接記述 */
@media screen and (max-width: 600px) {
  .container { width: 100%; }
}

/* CSS内の @import でも指定可能 */
@import url("mobile.css") screen and (max-width: 600px);
⚠️ @import は使用を避けることが推奨
@import によるCSSの読み込みは、 CSSファイルを直列で読み込むためパフォーマンスに影響します。 <link> 要素での読み込みの方がパフォーマンスに優れています。

② メディア型（Media Types）

重要ポイント②：画面やプリンタなど、対象にするメディアによりCSSを切り替えたいときには、メディア型を指定する
メディア型は「どの種類の出力デバイスか」を指定します。 省略した場合は all（すべてのメディア）として扱われます。
🖥️
screen
カラースクリーンを持つデバイス（PC・スマホ・タブレットなど）
🖨️
print
印刷・印刷プレビュー用。ページ区切りを持つ
🌐
all
すべてのメディア（省略時のデフォルト）
🔊
speech
音声合成デバイス（スクリーンリーダーなど）
⚠️ CSS3 で廃止されたメディア型
CSS2 では tty・tv・projection・handheld・ braille・embossed・aural などが定義されていましたが、 CSS3 では廃止されました。現在有効なのは screen・print・ all・speech の4つです。 
/* screen：画面向けのスタイル */
@media screen {
  body { font-size: 16px; }
}

/* print：印刷向けのスタイル */
@media print {
  nav, .sidebar, .ad { display: none; }  /* ナビ・広告を非表示 */
  body { font-size: 12pt; color: #000; }
  a::after { content: " (" attr(href) ")"; } /* URLを表示 */
}

/* all：すべてのメディア（メディア型省略と同じ） */
@media all and (min-width: 768px) { ... }
@media     (min-width: 768px) { ... }  /* 上と同じ */

③ メディア特性（Media Features）

重要ポイント③：画面幅など、対象メディアの特性によってCSSを切り替えたいときには、メディア特性を使用する
メディア特性は ( ) で囲んで指定します。 min- / max- プレフィックスで範囲指定ができるものもあります。

幅・高さ関連

/* width：ビューポートの幅 */
@media (width: 768px)        { ... }  /* ちょうど768px */
@media (min-width: 768px)    { ... }  /* 768px以上 */
@media (max-width: 767px)    { ... }  /* 767px以下 */

/* height：ビューポートの高さ */
@media (min-height: 600px)   { ... }  /* 高さ600px以上 */
@media (max-height: 500px)   { ... }  /* 高さ500px以下 */

/* device-width / device-height（CSS3では非推奨） */
/* → width / height を使うことが推奨 */

解像度・画素密度関連

/* resolution：解像度（dpi / dpcm / dppx） */
@media (min-resolution: 2dppx)  { ... }  /* Retina / 高解像度ディスプレイ */
@media (min-resolution: 192dpi)  { ... }  /* 同上（dpi指定） */

/* -webkit-device-pixel-ratio（非標準・Webkit系） */
@media (-webkit-min-device-pixel-ratio: 2) { ... }

向き・アスペクト比関連

/* orientation：デバイスの向き */
@media (orientation: portrait)   { ... }  /* 縦向き（高さ > 幅） */
@media (orientation: landscape)  { ... }  /* 横向き（幅 > 高さ） */

/* aspect-ratio：ビューポートのアスペクト比 */
@media (aspect-ratio: 16/9)       { ... }  /* ちょうど16:9 */
@media (min-aspect-ratio: 4/3)     { ... }  /* 4:3以上のアスペクト比 */

色関連

/* color：カラービット数 */
@media (color)                    { ... }  /* カラーデバイス（ビット数問わず） */
@media (min-color: 8)             { ... }  /* 8ビット以上のカラー */

/* prefers-color-scheme：ライト/ダークモードの設定 */
@media (prefers-color-scheme: dark)  { ... }  /* ダークモード */
@media (prefers-color-scheme: light) { ... }  /* ライトモード */

その他の主要なメディア特性

/* hover：ホバー操作が可能か */
@media (hover: hover)   { ... }  /* マウスなどホバー可能なデバイス */
@media (hover: none)    { ... }  /* タッチデバイスなどホバー不可 */

/* pointer：ポインティングデバイスの精度 */
@media (pointer: fine)   { ... }  /* マウスなど精度の高いポインタ */
@media (pointer: coarse) { ... }  /* タッチスクリーンなど精度の低いポインタ */
@media (pointer: none)   { ... }  /* ポインタなし */

/* prefers-reduced-motion：アニメーション軽減設定 */
@media (prefers-reduced-motion: reduce) {
  * { animation: none; transition: none; }
}
メディア特性説明min- / max-
widthビューポートの幅✅ 可
heightビューポートの高さ✅ 可
resolution解像度（dpi / dpcm / dppx）✅ 可
orientation向き（portrait / landscape）❌ 不可
aspect-ratioビューポートのアスペクト比✅ 可
colorカラービット数✅ 可
prefers-color-schemeライト/ダークモード❌ 不可
hoverホバー操作の可否❌ 不可
pointerポインタの精度❌ 不可
prefers-reduced-motionアニメーション軽減設定❌ 不可

④ 論理演算子（and / not / only / , ）

and
複数の条件をすべて満たすときに適用。 メディア型とメディア特性を組み合わせるときにも使う。
@media screen and (min-width: 768px) { ... }
not
条件を否定する。 メディアクエリ全体を否定するため、 メディア型の指定が必要。
@media not print { ... }
only
メディアクエリ非対応の古いブラウザに スタイルを適用させないための指定。 現代では省略可能。
@media only screen and (min-width: 768px) { ... }
,（カンマ）
複数の条件をいずれか満たすときに適用（OR条件）。 各条件は独立して評価される。
@media screen, print { ... }
/* and：複数条件をすべて満たす場合（AND条件） */
@media screen and (min-width: 768px) and (max-width: 1024px) {
  /* タブレット向け */
}

/* ,（カンマ）：いずれかを満たす場合（OR条件） */
@media screen, print {
  /* 画面または印刷 */
}
@media (max-width: 600px), (orientation: portrait) {
  /* 幅600px以下 または 縦向き */
}

/* not：条件を否定 */
@media not print {
  /* 印刷以外のすべてのメディア */
}

/* only：古いブラウザ対策（現代では省略可能） */
@media only screen and (min-width: 768px) { ... }

/* CSS Media Queries Level 4：range構文（新しい書き方） */
@media (768px <= width <= 1024px) {
  /* 768px以上1024px以下（andで書いた範囲指定と同等） */
}
✅ CSS Media Queries Level 4 の range 構文
新しい書き方では @media (768px <= width <= 1024px) のように 数学的な範囲指定が使えます。 ただし対応ブラウザを確認してから使用しましょう。

⑤ ブレークポイントの設定パターン

/* ===== よく使われるブレークポイント ===== */

/* モバイルファースト（min-width） */
/* デフォルト：スマートフォン（〜600px） */
.column { width: 100%; }

@media (min-width: 601px) {
  /* タブレット（601px〜） */
  .column { width: 50%; }
}
@media (min-width: 769px) {
  /* PC（769px〜） */
  .column { width: 33.333%; }
}
@media (min-width: 1200px) {
  /* 大画面（1200px〜） */
  .column { width: 25%; }
}

/* ===== デスクトップファースト（max-width） ===== */
/* デフォルト：PC */
.column { width: 25%; }

@media (max-width: 1199px) {
  .column { width: 33.333%; }
}
@media (max-width: 768px) {
  .column { width: 50%; }
}
@media (max-width: 600px) {
  .column { width: 100%; }
}

⑥ 実践的なメディアクエリの使用例

/* ===== ナビゲーションのレスポンシブ対応 ===== */
nav ul {
  display: flex;
  gap: 16px;
  list-style: none;
}
@media (max-width: 600px) {
  nav ul {
    flex-direction: column;  /* スマホでは縦並び */
  }
}

/* ===== 印刷用スタイル ===== */
@media print {
  header, footer, nav, .no-print {
    display: none;          /* 印刷時に不要な要素を非表示 */
  }
  body {
    font-size: 12pt;
    color: #000;
    background: none;
  }
  a { text-decoration: none; color: inherit; }
  a[href]::after {
    content: " (" attr(href) ")";  /* URLを表示 */
  }
}

/* ===== ダークモード対応 ===== */
@media (prefers-color-scheme: dark) {
  body {
    background: #1a202c;
    color: #e2e8f0;
  }
}

/* ===== 高解像度ディスプレイ（Retina）対応 ===== */
@media (min-resolution: 2dppx) {
  .logo {
    background-image: url("logo@2x.png");
    background-size: contain;
  }
}

/* ===== タッチデバイス向け（ホバー不可デバイス） ===== */
@media (hover: none) {
  .tooltip { display: none; }  /* ホバーで表示するツールチップを非表示 */
}

/* ===== アニメーション軽減設定への対応 ===== */
@media (prefers-reduced-motion: reduce) {
  *, *::before, *::after {
    animation-duration: 0.01ms !important;
    transition-duration: 0.01ms !important;
  }
}

}
